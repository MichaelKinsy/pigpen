# bench-bun

A bench Piglet for pi-arena: the Bun runtime slot is the only member. Members are Packages under `components/`; the Bun runtime slot is copied from PiG Standard ([credit](../../components/bun-runtime/CREDITS.md)).

Pin by Pigpen commit until PiG 0.5.0 ships (`release.version` is fixed), then by the pi-in-go.dev version. Build: `npm run stage`, then `npm run build:piglet -- bench-bun`.
