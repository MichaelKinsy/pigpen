# bench-standard

A bench Piglet for pi-arena: the two pig games and the Bun runtime slot, the members of PiG Standard that are not built into the core since 0.4.0. Members are Packages under `components/`; the Bun runtime slot is copied from PiG Standard ([credit](../../components/bun-runtime/CREDITS.md)).

Pin by Pigpen commit until PiG 0.5.0 ships (`release.version` is fixed), then by the pi-in-go.dev version. Build: `npm run stage`, then `npm run build:piglet -- bench-standard`.
