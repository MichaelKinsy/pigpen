## Native Dock Widget `kit.View` Contracts (`Lines("dock").View`)

PiG's `TuiSurface.dockEntries` (`tui/tui_surface.go:649-660`, `tui/tui_surface_view.go:94-124`) delivers above-editor extension widgets in `RegionDock` node `"dock"` (`frontend.Lines`) with a combined `View` whenever any widget uses `ctx.SetWidget(key, kit.View{Root: ...})`. Under `ompRoles`, `dock.go:ompView` + `omp_views.go:ompDockWidgetParts` place recognized omp dock widgets and the working/editor nodes into omp's fixed `nativeDock` slot containers (`interactive-mode.ts:2820-2835`): `btw`, `omfg`, `cleanse`, `errorBanner` (`col(row[omp.errorBanner])`), `modelCycle`, `deferred`, `above`, `activity` (`row[omp.hud.activity](col[omp.hud.status](row[omp.working]), checklist[omp.hud.todo])`), `pending`, `editor` (`col(col[omp.editor])`), `below`.
### 1. Todo HUD (`internal/todo` — `WidgetKey = "oh-my-pig:todo"`)
- Upstream: `packages/coding-agent/src/modes/interactive-mode.ts:5675-5705`
- Mounted whenever at least one phase has tasks (including when all tasks are done/dropped); cleared with `ctx.SetWidget(WidgetKey, nil)` only when 0 tasks remain.

  - Root: `&kit.VStack{ID: "omp.hud.todo", Gap: 0, Children: phaseNodes}`
  - Per non-empty phase `p` (`0`-based): `&kit.VStack{ID: "omp.todo.phase#<p>", Gap: 0, Children: ...}`

    - Per task `t` (`0`-based):
