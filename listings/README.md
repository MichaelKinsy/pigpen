# Third-party listings

One `<id>.json` per PiG Package or Piglet that Pigpen does not own, pinned to a full commit. See
[Third-party listings](../CONTRIBUTING.md#third-party-listings) for how to propose one and what CI checks.
The schema is [`listing.schema.json`](../listing.schema.json). `index.json` is generated from these files; never edit it.
