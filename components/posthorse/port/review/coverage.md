## Exclusions and skips checked as valid

* All 59 `quality-*`/`retained-qualification` skips: every TS file imports only `scripts/*` and `quality-support.ts` (none imports `index.ts`, `ui.ts` or `src/`); each reason matches its test. The 5 `quality-registrations` titles are fixture snippet names inside `expectFindings`.
* native 735 / 837 (x2): the upstream test itself calls `t.skip` unless codemode advertises `"background": true` (native-host.ts:765-773, 873-877).
* native 348, 596: layer-1 tests exist and assert the upstream outcome (596 through the production seam `noteAfterCopy`).
* native 994: `TestNativeHost_pageReadsEstimateCurrentActiveSchemasOnlyWhenUsageIsUnknown` exists (and kills the turn_start mutant).
* native 2690 (x2): covered by twins "history cursors finish partial headers and progress past growing lookup echoes" and "all-session cursors retain ranking and per-file entries across pages".
* official 606 (x2), 2322, 2347, 1172: layer-1 tests assert the extension's decision.
* Leftover scan of production Go: no `unported`, `TODO`, `FIXME`, `panic("`, `fmt.Print*`, `os.Stdout`, `os.Exit`, `log.Fatal`, `os.Chdir`, AI attribution; imports only `extensions/sdk`, `sdk/json`, `sdk/tui`. `os.Stderr` in rollover.go (C-15). `TEMPORARY-GATE` in notes.go/notes_order.go (C-16).
* TS surface: every `pi.on` (16 handlers), `registerTool` (4), `registerMessageRenderer` (2), `appendEntry` (3 types), `sendMessage` (reminder, steer), custom types (`posthorse-guidance`, `-retained-tail`, `-reset-deferred`, `-projection`, `-boundary`, `-notes-scope`, `-note-touch`, `context-window`, `posthorse-reminder`), `process.platform` (ARGUMENT_CHARS, win32 paths), `homedir`, `getAgentDir`, `execFile rg` (maxBuffer 64 MiB) has a Go counterpart; test coverage per item is in the mutation table.
