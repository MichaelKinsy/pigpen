# pig-hermes Component

Single fused Go PiG extension porting Nous Research's Hermes Agent tool surface, bounded memory (`MEMORY.md` / `USER.md`), progressive-disclosure skills, three-tier system prompt, session search & profiles, subagent delegation, cron management, web/MCP adapters, and Hermes slash commands & skins.

See `port/PORT.md` for the Kind 4 architecture mapping, upstream commit pin (`45e9584556a97f50a3cb6394a6e7f6afa97bb66a`), and verification evidence.
