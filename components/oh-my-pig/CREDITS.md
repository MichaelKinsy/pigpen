# Credits

`extensions/oh-my-pig` is a Go port of parts of **omp** (oh-my-pi), https://github.com/can1357/oh-my-pi, by
**Can Bölük** and **Stencil Labs, Inc.**, itself a fork of **pi** by **Mario Zechner** (MIT; the license is at
[licenses/oh-my-pi-LICENSE](licenses/oh-my-pi-LICENSE), unmodified).

- Original: the TypeScript omp on branch `main`, packages `coding-agent`, `browser-relay`, `tui`, `agent` and `utils`.
- Release tag `v19.1.1`, commit `31ffee513f27a01bba7d4dfbe12bae239cdc646a` (2026-11-23).
- What is taken from it: tool names, parameter schemas, tool descriptions and prompt text (copied, as the
  model-facing surface has to be the same to behave the same), and the behavior of each tool, written again
  in Go. Each package under `extensions/oh-my-pig/internal/` has an `UPSTREAM.md` that lists the original
  files it follows and what it leaves out.
- Generated JS cell rewriter bundle (`extensions/oh-my-pig/internal/eval/js_rewriter.cjs`, generated by
  `extensions/oh-my-pig/internal/eval/gen/build-rewriter.ts` with SHA-256 manifest
  `extensions/oh-my-pig/internal/eval/js_rewriter.manifest.json`): bundles omp's unmodified
  `packages/coding-agent/src/eval/js/shared/{rewrite-imports,indirect-eval,local-module-loader}.ts` at
  tag `v19.1.1` (`31ffee513f27a01bba7d4dfbe12bae239cdc646a`) together with **`@babel/parser`** `7.29.9` by
  The Babel Team (https://github.com/babel/babel, tag `v7.29.9`, commit
  `54405f212b4e6a40f0e1dfba9293b0e3f3dd20e3`, MIT; the license is at
  [licenses/babel-parser-LICENSE](licenses/babel-parser-LICENSE), unmodified).
- ARIA-snapshot bundle (`extensions/oh-my-pig/internal/browser/assets/aria-snapshot.bundle.txt`, embedded in
  the extension): copied unmodified from omp's `packages/coding-agent/src/tools/browser/aria/aria-snapshot.bundle.txt`
  at tag `v19.1.1`, which omp generates with its `scripts/generate-aria-snapshot.ts` from the injected
  ARIA-snapshot sources of **Playwright** `1.61.0` by **Microsoft Corporation**
  (https://github.com/microsoft/playwright, tag `v1.61.0`, commit
  `1cc5a90cfa3eaa430b1a991963100f95126caa47`, Apache-2.0; the license is at
  [licenses/playwright-LICENSE](licenses/playwright-LICENSE) and Playwright's notice at
  [licenses/playwright-NOTICE](licenses/playwright-NOTICE), both unmodified). The bundle is a minified
  build of those sources, not the sources themselves; nothing in it was changed for this Package.
- Generated relay-only Chrome extension bundle (`extensions/oh-my-pig/internal/relay/extension/`,
  generated by `extensions/oh-my-pig/internal/relay/gen/build-extension.ts` with patch
  `extensions/oh-my-pig/internal/relay/gen/relay-only.patch` and SHA-256 manifest
  `extensions/oh-my-pig/internal/relay/extension.manifest.json`): bundles the relay-only subset of omp's
  `packages/browser-relay` (service worker `background.js`, page overlay `overlay.js`, `manifest.json`,
  and upstream `LICENSE`) from tag `v19.1.1` (`31ffee513f27a01bba7d4dfbe12bae239cdc646a`, MIT;
  [licenses/oh-my-pi-LICENSE](licenses/oh-my-pi-LICENSE)). omp's icons are not shipped; the generator
  synthesizes oh-my-pig's own `icons/oh-my-pig-{16,32,48,128}.png` icons in code. The side panel, Teach
  recorder, schedules, and GIF export are removed by the patch, so the shipped extension bundle contains
  zero third-party npm runtime dependencies (no React, `lucide-react`, or `gifenc`).
- Document-to-Markdown converters (`extensions/oh-my-pig/internal/markit/`): Go port of omp's
  `packages/coding-agent/src/markit/` and `packages/utils/src/{docx,turndown}/` at tag `v19.1.1`.
  Portions of omp's DOCX, PPTX, XLSX, and EPUB converters are adapted from **`markit-ai`**
  (https://github.com/Michaelliv/markit) by **Michael Liv** (MIT; the license is at
  [licenses/markit-ai-LICENSE](licenses/markit-ai-LICENSE), unmodified).
- Embedded `omp://` harness docs bundle (`extensions/oh-my-pig/internal/urls/docs_index.generated.txt`,
  generated by `extensions/oh-my-pig/internal/urls/gen/gen_docs_index.py` with SHA-256 manifest
  `extensions/oh-my-pig/internal/urls/docs_index.manifest.json`): gzip-compressed, base64-encoded
  JSON map of omp's 135 unmodified `docs/**/*.md` files at tag `v19.1.1`
  (`31ffee513f27a01bba7d4dfbe12bae239cdc646a`, MIT; [licenses/oh-my-pi-LICENSE](licenses/oh-my-pi-LICENSE)).
