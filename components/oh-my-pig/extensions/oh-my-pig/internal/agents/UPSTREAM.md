## Agent discovery directory mapping (omp → PiG)

PiG exposes the host's config tree via `sdk.AgentDir()` (typically `~/.pig/agent`, or `~/.pi/agent` when sharing Pi's tree) and `sdk.ConfigDirName()` (typically `.pig`, or `.pi`). `DiscoverAgents` maps omp's roots in precedence order:
1. Nearest ancestor `<ConfigDirName>/agents/*.md` (project scope, e.g. `.pig/agents`), stopping at `$HOME`.
2. Nearest ancestor `.omp/agents/*.md` (project compatibility fallback if distinct).
3. `<AgentDir>/agents/*.md` (user scope, e.g. `~/.pig/agent/agents`).
4. `~/.omp/agent/agents/*.md` (user compatibility fallback if distinct).
5. Bundled agents (`scout`, `reviewer`, `security-reviewer`, `task`, `sonic`).

Cross-harness directories like `.claude/agents` are intentionally skipped, matching omp `discovery.ts`.
