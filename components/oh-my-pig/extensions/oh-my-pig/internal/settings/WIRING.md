# Settings Wiring Guide (`internal/settings`)

This document lists, per `oh-my-pig` area, the omp `v19.1.1` settings keys that area should read once the integrator wires `internal/settings` into the rest of the extension.

Every area can accept a feature-toggle function variable (e.g. `var enabledFn = settings.Enabled` wired by the integrator, or direct `settings.Bool` / `settings.Int` / `settings.Float` / `settings.String` / `settings.Strings` / `settings.Any` calls) so standalone package tests remain decoupled from disk configuration.

> **Security / operator-only note:** Upstream reads `bash.patterns` (for `deny`/`prompt` rules that project configs must not loosen), `task.perCallModel`, `task.perCallModelAllow`, and `auth.unpausedProviders` through `Settings.grantAuthority()` (project-free operator view). In `internal/settings`, use `settings.OperatorAny(ctx, key)` / `store.GetOperator(key)` for those checks.
