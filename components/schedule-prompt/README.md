# pigpen-schedule-prompt

Go port of [pi-schedule-prompt](https://github.com/tintinweb/pi-schedule-prompt) ("Pi's Heartbeat", by tintinweb, MIT): the agent
schedules future prompts, reminders and recurring jobs for itself, with a `schedule_prompt` tool, a live widget below the editor
and a `/schedule-prompt` manager. Go only; no Node at runtime.

**Status: honest-refusal skeleton (0.1.0).** The tool and the command are registered with the original's definition, but nothing
is scheduled yet. Every use is refused with

> @pi-in-go/pigpen-schedule-prompt (Go port) does not support <feature> yet. Install the original extension, npm:pi-schedule-prompt@0.4.1, which runs unchanged in PiG.

The port is delivered in slices; see [port/PORT.md](port/PORT.md) (inventory) and [port/slices.json](port/slices.json).
