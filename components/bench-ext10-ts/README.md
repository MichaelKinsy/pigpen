# bench-ext10-ts

The ten bench-ext extensions of the overhead bench as TypeScript files (one tool, one command and four event handlers each; no imports, no dependencies). The [`bench-ext10-aot`](../../piglets/bench-ext10-aot/piglet.yaml) Piglet carries them with the aot runtime. Source and credit: [CREDITS.md](CREDITS.md).
