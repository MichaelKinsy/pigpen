# Deferred skips of the async lane

Every case below is an individual `tskip` that is only acceptable until the owning slice lands. The final reconciliation converts each into a twin (the skips that remain at the end must be Node/Bun-loader internals only). The last column is what must exist in the Go port for the upstream case to be twinned.
